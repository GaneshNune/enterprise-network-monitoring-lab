# Wireshark Packet Analysis

## Objective

Analyze common network protocols using Wireshark.

## ICMP

ICMP traffic was generated using ping.

ICMP Echo Request packets were observed followed by Echo Reply packets when the destination responded.

## DNS

DNS traffic was generated using hostname resolution.

DNS queries were observed and analyzed to understand hostname-to-IP resolution.

## ARP

ARP traffic was analyzed to understand IPv4-to-MAC address resolution on the local network.

## Key Observations

- ICMP is commonly used for connectivity testing.
- DNS resolves hostnames to IP addresses.
- ARP resolves local IPv4 addresses to MAC addresses.
- Wireshark can be used to inspect packet-level behavior during troubleshooting.
